# Squareful-Create-Delight

本仓库为 Squareful 资源包（作者：Xe_Kr）的附属扩展，用于在 Create Delight Remake（CDR）及相关模组组合中提供兼容纹理与补充素材。本扩展严格遵守 Squareful 所在仓库中声明的扩展许可（EXTENSION_LICENSE）及主许可（CC BY-NC-ND 4.0），并且为非独立包 —— 必须与主资源包 Squareful 一同使用。

功能简介
- 为 Create Delight Remake（CDR）及列出的模组提供风格一致的纹理补充与兼容素材（例如色调调整、缺失物品/方块的配套纹理等）。
- 严格限制为“扩展”内容：不包含可替代主包的完整纹理资源，某些关键纹理需主包提供。

安装说明
1. 下载并安装 Squareful（主资源包）。主包仓库/发行页：https://github.com/XeKr/Squareful 或 Modrinth 链接（如适用）。
2. 将本扩展放入 Minecraft 的 resourcepacks 目录。
3. 在资源包界面中启用：建议先启用 Squareful，再启用本扩展（确保本扩展位于主包之下/已列为附加）。
4. 若以模组打包/Modpack 方式发布，请在 manifest 中将 Squareful 列为 prerequisite（前置依赖）。
